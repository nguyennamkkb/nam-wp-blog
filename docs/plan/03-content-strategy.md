# 3. Chiến lược nội dung

> Tài liệu tham chiếu · Cập nhật: 2026-11-08 · [Mục lục](../README.md) · [Backlog công việc](../tasks/README.md)


## 3.1 Content pillars

| Pillar | Nội dung | Ví dụ |
|---|---|---|
| **LLM Systems** | RAG, agents, tool use, memory, orchestration | “RAG từ số 0: chunking nào thực sự tốt?” |
| **Production AI** | Evaluation, observability, cost, latency, reliability | “Đo cost LLM theo request trong production” |
| **AI Tooling** | Local models, inference, framework, workflow | “Chạy LLM local trên máy 32GB RAM” |
| **Experiments & Benchmarks** | So sánh, đo đạc, war stories | “3 cách giảm latency RAG 40%” |
| **Craft** | Kỹ năng AI engineer, system design, career | “AI engineer cần biết gì ngoài prompt?” |

## 3.2 Formats & cadence

| Format | Độ dài | Tần suất | Mục tiêu |
|---|---|---|---|
| Deep dive | 3.000–5.000 từ | 1/tháng | Authority, SEO dài hạn |
| Tutorial | 1.500–3.000 từ | 2/tháng | Search traffic, practical value |
| Field note | 500–1.200 từ | 2/tháng | Nhịp đều, chia sẻ nhanh |
| Series | 3–6 phần | 3 series/90 ngày | Depth, returning readers |
| Benchmark | tùy | 1/quý | Khác biệt, trích dẫn |

**Cam kết tối thiểu:** 4 bài/tháng. Nhịp lý tưởng: 6 bài/tháng.

## 3.3 Editorial workflow

1. **Idea** — ghi vào backlog, chấm điểm: audience fit, originality, search intent, khả năng tái lập.
2. **Outline** — TL;DR, 3–5 luận điểm, code/benchmark cần làm.
3. **Draft** — viết trong WordPress block editor; code chạy thật.
4. **Technical review** — tự review bằng checklist: claim nào chưa kiểm chứng? số đo có nguồn?
5. **Edit** — mở bài, tiêu đề, heading, ví dụ, kết luận, internal links.
6. **Assets** — cover 1200×630, diagram, alt text, OG image.
7. **Publish** — slug, excerpt, category, series, tags, SEO meta, canonical.
8. **Distribute** — RSS, LinkedIn, Facebook group, dev.to (canonical về blog).
9. **Measure** — sau 7/30 ngày: traffic, search terms, scroll depth, comments (ngoài site).
10. **Update** — cập nhật số liệu, đánh dấu “Last updated”.

## 3.4 Phân phối

- **SEO:** topic clusters, internal links, schema, sitemap.
- **AI search:** HTML semantic, `llms.txt`, nội dung gốc có thể trích dẫn.
- **RSS:** kênh sở hữu, không phụ thuộc thuật toán.
- **Cộng đồng:** LinkedIn, Facebook groups, Vietnamese AI/dev communities.
- **Cross-post:** dev.to/Hashnode với canonical tag.
- **Newsletter:** Phase 2 (chưa nằm trong MVP).

## 3.5 Chính sách cập nhật

- Bài tutorial: review mỗi 6 tháng.
- Bài benchmark: review khi có model/framework mới đáng kể.
- Ghi rõ ngày cập nhật, thay đổi chính, và giữ phiên bản cũ nếu cần.
