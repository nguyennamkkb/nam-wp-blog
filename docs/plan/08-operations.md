# 8. Vận hành & đo lường

> Tài liệu tham chiếu · Cập nhật: 2026-11-08 · [Mục lục](../README.md) · [Backlog công việc](../tasks/README.md)


## 8.1 Dashboard tuần

- WER, returning readers.
- Top 5 bài theo traffic và engagement.
- Search terms (Umami/Search Console).
- LCP/INP/CLS.
- 5xx, 404, PHP errors.
- Số bài publish so với kế hoạch.

## 8.2 Bảo trì

| Tần suất | Việc |
|---|---|
| Hằng tuần | Update plugin trên staging, kiểm tra backup, xem log |
| Hằng tháng | Update WP/plugin production, CWV, security scan, content audit |
| Hằng quý | Restore drill, prune/update content, review strategy |
| Hằng năm | Review hosting, domain, stack, mục tiêu |

## 8.3 Quy ước nội dung

- Slug tiếng Anh, ngắn, không dấu.
- Title ≤ 60 ký tự nếu có thể; meta description 140–160 ký tự.
- Mỗi bài: 1 featured image, 1 TL;DR, 3–5 internal links, alt text.
- Code block có ngôn ngữ, copy được, không chứa secret.
- Bài cũ cập nhật phải ghi “Cập nhật lần cuối”.
